# NTOU 電機學習島

以 AI 協助製作的國立臺灣海洋大學電機工程學系課程互動網站。

## 功能
- 海洋風格五座互動課程島
- 課程搜尋與內容彈窗
- 六選三選課體驗（僅互動展示，非正式選課）
- 六大專業學習方向
- 響應式手機及電腦版型

## 如何使用
直接用瀏覽器開啟 `index.html`，不需要安裝任何套件或伺服器。

## GitHub Pages 發布
1. 在 GitHub 建立 Public repository，例如 `ntou-learning-island`。
2. 上傳 `index.html` 和 `README.md` 到主分支根目錄。
3. 開啟 Settings → Pages → Build and deployment，選擇 `Deploy from a branch`、`main`、`/(root)`，按 Save。
4. 看到 Pages 公布的網址後，開啟測試五座島、搜尋與六選三按鈕。
5. 依老師規定繳交 GitHub 連結或網頁網址。

## 資料來源與聲明
根據課堂提供的「電機系大學部必修與核心課程關聯圖」整理課名、六選三課程與六個專業組。課程介紹是一般性學習導覽，不代表學校正式課綱或最新選課規則。

## 六選三專業方向推薦

選滿三門課後會呈現六大方向的相對主題關聯分數、推薦理由與延伸探索主題，也能重新選擇。此為本網站自行設計的教育探索規則，非官方選課、分組或職涯測評。


## 人物導覽
地圖中的大一、大二、大三、大四學生與虛擬系主任可點擊，彈出對話並導向相關課程島。人物及對話為教學示意，不指涉真實系主任，年級配置也非官方課表。


## 場景化人物導覽版
此版本將大一至大四學生與虛擬系主任做成站在島上的互動角色，點擊可開啟導覽對話並導向對應內容，視覺上更接近老師提到的「島上小人」概念。
